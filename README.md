# BARDIA

> **Outdoor Performance + Data**
> Plataforma profesional de gestión, métricas, evolución e informes para entrenadores de running, trail running y deportes de montaña.

---

## 🏔️ Identidad y Concepto

Inspirada en el relieve, el desnivel y la superación que representan las bardas neuquinas:
* **Terreno y desnivel:** Datos precisos de altimetría y volumen.
* **Evolución continua:** Métricas claras de rendimiento a lo largo del tiempo.
* **Profesionalismo:** Informes A4 de alta fidelidad para el alumno.

---

## 🛠️ Stack Tecnológico

- **Frontend:** Next.js 15+ (App Router), React 19, TypeScript, Tailwind CSS, Lucide Icons.
- **Backend / Database:** Supabase PostgreSQL con Row Level Security (RLS) multi-tenant.
- **Autenticación & Storage:** Supabase Auth (SSR) y Supabase Storage para documentación confidencial.
- **Informes:** Generador vectorial de informes en PDF.

---
